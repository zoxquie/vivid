Put your own game screenshots here to build them into Vivid.exe as the default images.

File names (case, spaces and dashes don't matter; .jpg, .png or .bmp):
  grass.jpg         Grass preset card
  winter.jpg        Winter preset card
  desert.jpg        Desert preset card
  night-vision.jpg  Night Vision preset card
  custom.jpg        Custom card
  preview.jpg       Before/after live preview

Then rebuild (build.sh or dotnet build). Any preset without an image keeps the generated artwork.
The same names also work in an "images" folder placed next to Vivid.exe, no rebuild needed.
